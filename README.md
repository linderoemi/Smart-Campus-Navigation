# Smart-Campus-Navigation
Project for CSCE 2110 to utilize hash table, graph, and tree data structures

# Compiling
To compile this program, please use `g++ -Iinclude src/main.cpp src/FacilityDatabase.cpp src/HashTable.cpp src/Graph.cpp -o program_name` in the linux terminal and run the program using ./program_name. <program_name> can be changed to whatever you wish to name the final output file.
